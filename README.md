# veronoicc's Home Assistant Add-ons

Custom Home Assistant OS add-ons repository.

[![Add Repository on Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fveronoicc%2Fhomeassistant-addons)

## Adding this repository to Home Assistant

1. In Home Assistant, navigate to **Settings → Add-ons → Add-on Store**.
2. Click the three dots (top right) → **Repositories**.
3. Add repository URL:
   ```
   https://github.com/veronoicc/homeassistant-addons
   ```
4. Click **Add**, then reload / check for updates.
